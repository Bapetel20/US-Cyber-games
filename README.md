# US-Cyber-games
Network forensics challenge involving the analysis of a multi-stage cyberattack targeting an industrial SCADA environment. Investigated 6 packet captures to reconstruct a full attack chain from initial intrusion to PLC manipulation

What I Did

Analyzed 6 network packet captures using Wireshark to identify attack stages and threat actor behavior
Identified external intrusion via RDP/SSH brute force activity
Detected Ettercap ARP poisoning used for man-in-the-middle positioning on the network
Uncovered HMI credential exposure leading to unauthorized access
Traced direct PLC manipulation using EtherNet/IP and CIP/PCCC protocol analysis

Tools & Technologies

Wireshark — packet capture analysis and display filtering
Ettercap — ARP poisoning identification
ICS/SCADA protocols — EtherNet/IP, CIP/PCCC
HMI analysis — credential exposure and session tracing

Skills Demonstrated

Network forensics and traffic analysis
ICS/SCADA security
Threat actor behavior reconstruction
Protocol-level investigation (Layer 2–7)
